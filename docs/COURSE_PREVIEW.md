# 安卓原生课堂测试版

基于 Zeeo2440/FocuBili 已成功构建的提交 `22e2f96eed68bcf853bb438d89c04685a0556fb7`。
本次将网页兼容入口替换为原生播放器入口。

## 使用方式

安装后应用名称为 **焦点哔哩·课堂**，测试包名为 `com.focubili.app.course`。
它可以与正式版、之前的网页测试版共存，无需卸载旧版；首次需要重新登录购买课程的账号。

在搜索框粘贴 `https://www.bilibili.com/cheese/play/ss968174948`。
课程目录加载后进入现有播放器，可选集、倍速、拖动、全屏、加入学习清单和记录时间点笔记。
学习记录保存在当前测试应用本机，不等于同步 B站官方课堂学习进度。
从观看记录、学习清单和笔记返回课程，会重新读取目录并检查播放权限。
`ep` 章节链接优先打开指定章节，`ss` 课程链接按现有续播策略恢复。

## 实现

- 官方课程目录：`/pugv/view/web/season`，分页时使用 `/pugv/view/web/ep/list`。
- 官方课程播放：`/pugv/player/web/playurl`，发送真实 `avid`、`ep_id`、`cid` 和当前账号会话。
- Android 复用 Media3 和现有播放事件、倍速、清晰度、续播、学习/笔记逻辑。
- 用 `cheese:ss<课程ID>` 作为本地内容键，与普通 BV 记录隔离；章节保留真实 CID、ep_id 和 aid。
- 登录态由原有 Cookie 容器提供。权限不足/会话变化时报告错误，不改写权限或尝试替代账号。
- 原生支持标准 DASH 和单段合流媒体；遇到试看标记、明确 DRM 或暂不支持的多段合流媒体会提示。
- 课堂离线下载、独立字幕和弹幕暂未接入；学习清单、时间点笔记可用。

## 更新 GitHub（只需浏览器）

1. 解压更新包，在自己的仓库首页使用 Add file → Upload files，把 `android`、`lib`、`test`、`docs` 四个文件夹拖进去，提交到 master。
2. `.github` 文件夹可能被网页拖拽忽略。请进入仓库 `.github/workflows/android-course-preview.yml`，点铅笔编辑，将本包同名文件内容全部复制进去，提交。
3. Actions → Android course preview → Run workflow → master。
4. 运行成功后下载 Artifacts 的 `FocuBili-course-preview-debug`，解压 APK 安装。
5. 如果构建失败，保留第一条失败步骤的完整日志；不要删除检查步骤来强行打包。

## 平板验收

- 登录购买账号，先播一个付费章节，确认声音、画面、拖动、倍速和全屏。
- 观看至约一分钟，退出，再从观看记录打开，确认章节和进度恢复。
- 分别将两节课加入学习清单，确认进度独立保存。
- 添加一条时间点笔记，退出后从笔记进入，确认定位到对应章节和时间。
- 退出账号或换到未购账号后，付费章节应显示权限提示。
- 检查普通 BV 视频仍可播放。

本地记录随测试应用保存。不要为了更新而直接清除数据；后续若提示签名不一致，先备份再处理。
